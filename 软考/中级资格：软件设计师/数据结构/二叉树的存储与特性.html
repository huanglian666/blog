2. 考点：二叉树的定义

2.1 二叉树的定义

  • 二叉树是 nnn (n≥0n \ge 0n≥0) 个结点的有限集合。
  • 它或者是空树 (n=0n = 0n=0)，或者是自由一个根结点及两棵不相交的、分别称为左子树和右子树的二叉树所组成。
  • 核心性质：二叉树具有明显的递归性质（即子树本身也是二叉树）。
  • 注意事项：二叉树的度最大为 222，且结点的左右子树是有序的、不能颠倒。

2.2 二叉树的常见形态

  • 空树：没有任何结点的树（n=0n = 0n=0）。
  • 单节点树：只包含 111 个结点的树。
  • 单支树：每个分支结点都只有左子树或只有右子树的树（形态类似于链表）。
  • 一般形态 / 满二叉树：具有根结点以及完整的左右子树分支结构。

2.2.1 完全二叉树的定义

  • 核心概念：把二叉树节点按照满二叉树的顺序进行编号后，如果所有节点的编号是完全连续的（即中间没有任何空缺），就叫做完全二叉树。

  • 直观理解：

    • 叶子节点只能出现在最下两层。
    • 最下层的叶子节点必须集中在该层的左侧，连续排列。
    • 倒数第二层的右侧可以不饱满，但如果右侧有节点，其左侧必须是全满的。

2.2.2 完全二叉树与非完全二叉树辨析

  • 完全二叉树特征：

    • 节点从上到下、从左到右依次紧凑排列，编号连续无中断（例如节点编号依次为 1,2,3,4,51, 2, 3, 4, 51,2,3,4,5 或 1,2,3,4,5,61, 2, 3, 4, 5, 61,2,3,4,5,6）。

  • 非完全二叉树特征：

    • 节点排列出现断层或跳跃（例如左边未排满，右边却出现了较大编号如 777，或者底层叶子节点在左边有空缺的情况下右边出现节点）。

  1. 父结点关系：

  • 核心思路：如果树中的节点未按常规完全二叉树的紧凑层序编号，可以通过其父子关系公式（左孩子 2i2i2i、右孩子 2i+12i+12i+1、父节点 ⌊i/2⌋\lfloor i / 2 \rfloor⌊i/2⌋）反推其在标准满二叉树/完全二叉树中对应的正确层序编号。

4.3 二叉树的节点度数与性质定理 (n0=n2+1n_0 = n_2 + 1n0​=n2​+1)

对任何一棵二叉树，如果其叶子结点数为 n0n_0n0​，度为 222 的结点数为 n2n_2n2​，则恒有关系：

n0=n2+1n_0 = n_2 + 1 n0​=n2​+1

4.3.1 核心符号定义

  • n0n_0n0​：度为 000 的结点数（即叶子结点数）。
  • n1n_1n1​：度为 111 的结点数。
  • n2n_2n2​：度为 222 的结点数。
  • 推广到一般树：nkn_knk​ 表示度为 kkk 的结点数。

4.3.2 双向推导过程

  1. 视角一：从根向叶子伸展（计算总分支数）

    • 根据度的定义，度为 kkk 的结点会伸出 kkk 个分支。

    • 因此，整棵树的总分支数（边数）可以通过所有结点的度数加权求和得出：

      分支数=∑i=0k(i×ni)=n0×0+n1×1+n2×2+⋯+nk×k\text{分支数} = \sum_{i=0}^{k} (i \times n_i) = n_0 \times 0 + n_1 \times 1 + n_2 \times 2 + \dots + n_k \times k 分支数=i=0∑k​(i×ni​)=n0​×0+n1​×1+n2​×2+⋯+nk​×k

  • 视角二：从叶子向根回溯（利用父子连线关系）

    • 在树形结构中，每个结点都会通过恰好 111 根分支与其父结点相连，唯一的例外是根结点（根结点没有父结点，没有向上的连线）。

    • 因此，总分支数等于“结点总数减去根结点”，即：

      分支数=结点总数−1=(n0+n1+n2+⋯+nk)−1\text{分支数} = \text{结点总数} - 1 = (n_0 + n_1 + n_2 + \dots + n_k) - 1 分支数=结点总数−1=(n0​+n1​+n2​+⋯+nk​)−1

  • 联立方程与二叉树化简

    • 将两种方式算出的总分支数联立：

      (n0+n1+n2+⋯+nk)−1=n0×0+n1×1+n2×2+⋯+nk×k(n_0 + n_1 + n_2 + \dots + n_k) - 1 = n_0 \times 0 + n_1 \times 1 + n_2 \times 2 + \dots + n_k \times k (n0​+n1​+n2​+⋯+nk​)−1=n0​×0+n1​×1+n2​×2+⋯+nk​×k

    • 对于二叉树而言，最大的度不超过 222（即 n3=n4=⋯=0n_3 = n_4 = \dots = 0n3​=n4​=⋯=0），代入上式得：

      (n0+n1+n2)−1=n0×0+n1×1+n2×2(n_0 + n_1 + n_2) - 1 = n_0 \times 0 + n_1 \times 1 + n_2 \times 2 (n0​+n1​+n2​)−1=n0​×0+n1​×1+n2​×2

    n0+n1+n2−1=n1+2n2n_0 + n_1 + n_2 - 1 = n_1 + 2n_2 n0​+n1​+n2​−1=n1​+2n2​

  • 两边同时消去 n1n_1n1​：

    n0+n2−1=2n2  ⟹  n0=n2+1n_0 + n_2 - 1 = 2n_2 \implies n_0 = n_2 + 1 n0​+n2​−1=2n2​⟹n0​=n2​+1

4.3.3 重要解题技巧

  • 通用规律：对于任何非空树（无论是否为二叉树），结点的数量=分支数量+1\text{结点的数量} = \text{分支数量} + 1结点的数量=分支数量+1。

4.4 具有 NNN 个结点的二叉树形态数

4.4.1 核心公式与递推原理

  • 形态数递推公式：

    A[N]=∑M=0N−1(A[M]×A[N−M−1])A[N] = \sum_{M=0}^{N-1} (A[M] \times A[N-M-1]) A[N]=M=0∑N−1​(A[M]×A[N−M−1])

(注：该公式本质上即为卡特兰数 / Catalan Number 的应用)

  • 核心原理：
    从 NNN 个结点中抽出 111 个结点作为根结点，剩余的 N−1N-1N−1 个结点被分配到左右两侧子树中。设左子树有 MMM 个结点，则右子树就有 N−M−1N-M-1N−M−1 个结点。左右子树形态数的乘积之和即为总形态数。

4.4.2 具体实例推导

  • (1) 000 个结点的二叉树形态数：

    • 111 种：空树 (A[0]=1A[0] = 1A[0]=1)。

  • (2) 111 个结点的二叉树形态数：

    • 111 种：单结点树 (A[1]=1A[1] = 1A[1]=1)。

  • (3) 222 个结点的二叉树形态数：

    • 222 种：根带左孩子或根带右孩子 (A[2]=2A[2] = 2A[2]=2)。

  • (4) 333 个结点的二叉树形态数：

    • 555 种：

      A[3]=A[0]A[2]+A[1]A[1]+A[2]A[0]A[3] = A[0]A[2] + A[1]A[1] + A[2]A[0] A[3]=A[0]A[2]+A[1]A[1]+A[2]A[0]

    A[3]=(1×2)+(1×1)+(2×1)=5 种A[3] = (1 \times 2) + (1 \times 1) + (2 \times 1) = 5 \text{ 种} A[3]=(1×2)+(1×1)+(2×1)=5 种

5.2 题目二

题目： 设某二叉树采用二叉链表表示（即结点的两个指针分别指示左、右孩子）。当该二叉树包含 kkk 个结点时，其二叉链表结点中必有（ C ）个空的孩子指针。

  • A. k−1k - 1k−1
  • B. kkk
  • C. k+1k + 1k+1
  • D. 2k2k2k

【解析】

  1. 计算总指针数：

    • 二叉树采用二叉链表存储时，每个结点都包含两个指针域（左孩子指针和右孩子指针）。

    • 当树中包含 kkk 个结点时，指针域总数为：

      总指针数=2k\text{总指针数} = 2k 总指针数=2k

  • 计算非空指针数（有效孩子指针） ：

    • 在树形结构中，除了根结点没有父结点外，其余每个结点都由其父结点的某一个孩子指针指向。
    • 因此，指向子结点的非空指针数量恰好等于树中的分支数（边数） 。
    • 对于有 kkk 个结点的树，分支数恒等于 k−1k - 1k−1。

  • 计算空指针数（叶子或单支结点的空链域） ：

    • 空指针数等于“总指针数”减去“非空指针数”：

      空指针数=2k−(k−1)=2k−k+1=k+1\text{空指针数} = 2k - (k - 1) = 2k - k + 1 = k + 1 空指针数=2k−(k−1)=2k−k+1=k+1

正确答案：C. k+1k+1k+1 。
