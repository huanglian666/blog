队列与栈

1. 考点：队列与栈的基本特点

2. 考点：循环队列

2.1 基本概念

  • 循环队列​：通过数组实现并通过整数取余运算来实现首尾相连的环形队列，从而解决普通队列假溢出问题。
  • 最大优点​：相比普通队列，入队和出队操作都​不需要移动队列中的其他元素。

2.2 核心公式与条件（假设队列总容量为 ​size）

  • 队空条件：

    head=tail\text{head} = \text{tail} head=tail

  • 队满条件：

    (tail+1)%size=head(\text{tail} + 1) \% \text{size} = \text{head} (tail+1)%size=head

(注：通常会浪费一个存储单元来区分队空和队满)

  • 队列长度计算公式：

    (tail−head+size)%size(\text{tail} - \text{head} + \text{size}) \% \text{size} (tail−head+size)%size

3. 经典例题

3.1 题目一

题目： 设有栈 SSS 和队列 QQQ 初始状态为空，数据元素序列 a,b,c,d,e,fa, b, c, d, e, fa,b,c,d,e,f 依次通过栈 SSS，且多个元素从 SSS 出栈后立即进入队列 QQQ，若出队的序列是 b,d,f,e,c,ab, d, f, e, c, ab,d,f,e,c,a，则 SSS 中的元素最多时，栈底到栈顶的元素依次为（ C ）。

  • A. a,b,ca, b, ca,b,c
  • B. a,c,da, c, da,c,d
  • C. a,c,e,fa, c, e, fa,c,e,f
  • D. a,d,f,ea, d, f, ea,d,f,e

详细解析：

  1. 明确队列的进出规律：

    • 队列 QQQ 是先进先出（FIFO）的。既然题目给出的最终出队序列是 b,d,f,e,c,ab, d, f, e, c, ab,d,f,e,c,a，说明元素进入队列 QQQ 的顺序必然也是 ​**b,d,f,e,c,ab, d, f, e, c, ab,d,f,e,c,a**。
    • 因为元素是从栈 SSS 出栈后立即进入队列 QQQ 的，所以元素从栈 SSS 出栈的顺序也必须是：​**b→d→f→e→c→ab \rightarrow d \rightarrow f \rightarrow e \rightarrow c \rightarrow ab→d→f→e→c→a**。

  2. 模拟进栈与出栈过程：
    我们要按照上述出栈顺序，配合输入序列 a,b,c,d,e,fa, b, c, d, e, fa,b,c,d,e,f 来推导栈 SSS 的变化状态：

    • 目标 1：先出栈 bbb

      • 必须先将 aaa 入栈，再将 bbb 入栈。
      • 此时栈 SSS（栈底到栈顶）：[a,b][a, b][a,b]
      • 出栈 bbb（进入队列 QQQ）。此时栈 SSS 剩：[a][a][a]

    • 目标 2：接着出栈 ddd

      • 必须先将 ccc 入栈，再将 ddd 入栈。
      • 入栈 ccc 后，栈 SSS：[a,c][a, c][a,c]
      • 入栈 ddd 后，栈 SSS：[a,c,d][a, c, d][a,c,d]
      • 出栈 ddd（进入队列 QQQ）。此时栈 SSS 剩：[a,c][a, c][a,c]

    • 目标 3：接着出栈 fff

      • 必须先将 eee 入栈，再将 fff 入栈。
      • 入栈 eee 后，栈 SSS：[a,c,e][a, c, e][a,c,e]
      • 入栈 fff 后，栈 SSS：[a,c,e,f][a, c, e, f][a,c,e,f] （​此时栈中元素最多，共 444 个）
      • 出栈 fff（进入队列 QQQ）。此时栈 SSS 剩：[a,c,e][a, c, e][a,c,e]

    • 后续出栈（验证）：

      • 依次出栈 eee →\rightarrow→ 栈 SSS 剩：[a,c][a, c][a,c]
      • 依次出栈 ccc →\rightarrow→ 栈 SSS 剩：[a][a][a]
      • 依次出栈 aaa →\rightarrow→ 栈 SSS 为空。

正确答案：C. a,c,e,fa, c, e, fa,c,e,f 。

3.2 题目二

题目： 双端队列是指在队列的两个端口都可以加入和删除元素，如下图所示。现在要求元素进队列和出队列必须在同一端口，即从 A 端进队的元素必须从 A 端出，从 B 端进队的元素必须从 B 端出。则对于 4 个元素的序列 a,b,c,da, b, c, da,b,c,d，若要求前 2 个元素（a,ba, ba,b）从 A 端口按次序全部进入队列，后两个元素（c,dc, dc,d）从 B 端口按次序全部进入队列，则不可能得到的出列序列是（ A ）。

  • A. d,a,b,cd, a, b, cd,a,b,c
  • B. d,c,b,ad, c, b, ad,c,b,a
  • C. b,a,d,cb, a, d, cb,a,d,c
  • D. b,d,c,ab, d, c, ab,d,c,a

详细解析：

  1. 理解题目规则（等效模型）：

    • 元素 a,ba, ba,b 从 A 端进，也必须从 A 端出 —— 这相当于一个​独立的栈 SAS_ASA​（只能对 a,ba, ba,b 进行进栈和出栈操作）。
    • 元素 c,dc, dc,d 从 B 端进，也必须从 B 端出 —— 这相当于另一个​独立的栈 SBS_BSB​（只能对 c,dc, dc,d 进行进栈和出栈操作）。
    • 因此，整个结构被拆分成了两个互不干涉的独立栈：栈 **SAS_ASA​**​ （管理 a,ba, ba,b​ ） 和 ​栈 **SBS_BSB​**​ （管理 **c,dc, dc,d**​ ） 。

  2. 分析两个栈的内部出栈规律：

    • 对于 ​栈 SAS_ASA​（元素 a,ba, ba,b 依次入栈）：其合法的出栈顺序只能是 ​**b,ab, ab,a**。
    • 对于 ​栈 SBS_BSB​（元素 c,dc, dc,d 依次入栈）：其合法的出栈顺序只能是 ​**d,cd, cd,c**。
    • 核心约束​：最终的全局出栈序列，必须是这两个独立子序列交织（归并）的结果，但​绝对不能破坏各自内部原有的相对先后顺序（即 aaa 必须在 bbb 之后出栈，ccc 必须在 ddd 之后出栈）。

  3. 逐项验证选项：

    • 选项 A：​**d,a,b,cd, a, b, cd,a,b,c**

      • 检查 aaa 和 bbb 的相对顺序：在序列中 aaa 在 bbb 前面（aaa 先出栈，bbb 后出栈），这违背了栈 SAS_ASA​ 必须先出 bbb 再出 aaa 的原则。因此该序列​不可能得到（正确答案）。

    • 选项 B：​**d,c,b,ad, c, b, ad,c,b,a**

      • c,dc, dc,d 的顺序是 ddd 在 ccc 前（符合 SBS_BSB​）；a,ba, ba,b 的顺序是 bbb 在 aaa 前（符合 SAS_ASA​）。合法。

    • 选项 C：​**b,a,d,cb, a, d, cb,a,d,c**

      • a,ba, ba,b 的顺序是 bbb 在 aaa 前（符合 SAS_ASA​）；c,dc, dc,d 的顺序是 ddd 在 ccc 前（符合 SBS_BSB​）。合法。

    • 选项 D：​**b,d,c,ab, d, c, ab,d,c,a**

      • a,ba, ba,b 的相对顺序中 bbb 先出；c,dc, dc,d 的相对顺序中 ddd 先出。合法。

正确答案：A. d,a,b,cd, a, b, cd,a,b,c 。
