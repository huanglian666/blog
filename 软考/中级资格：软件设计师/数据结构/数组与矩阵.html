数组与矩阵

1. 考点：数组与矩阵的存储地址计算

1.1 基本概念

  • 下标规则：在计算机中，数组的下标一般从 000 开始计算。

  • 符号说明：

    • aaa：数组的起始内存地址（基地址）。
    • len\text{len}len：单个元素所占用的字节数（存储长度）。

1.2 一维数组的存储地址

  • 对于一维数组 a[n]a[n]a[n]，元素 a[i]a[i]a[i] 的存储地址计算公式为：

    Loc(a[i])=a+i×len\text{Loc}(a[i]) = a + i \times \text{len} Loc(a[i])=a+i×len

1.3 二维数组的存储地址

对于二维数组 a[m][n]a[m][n]a[m][n]（其中 mmm 为行数，nnn 为列数），由于计算机内存是线性的（一维的），因此二维数组在内存中存储时必须将其展开为一维线性排列。主要有两种存储方式：

  • 按行存储（Row-Major Order） ：先存第一行，再存第二行 …\dots… 以此类推。元素 a[i][j]a[i][j]a[i][j] 的存储地址计算公式为：

    Loc(a[i][j])=a+(i×n+j)×len\text{Loc}(a[i][j]) = a + (i \times n + j) \times \text{len} Loc(a[i][j])=a+(i×n+j)×len

(解释：前面完整的有 iii 行，每行有 nnn 个元素；当前行已经走了 jjj 个元素。)

  • 按列存储（Column-Major Order） ：先存第一列，再存第二列 …\dots… 以此类推。元素 a[i][j]a[i][j]a[i][j] 的存储地址计算公式为：

    Loc(a[i][j])=a+(j×m+i)×len\text{Loc}(a[i][j]) = a + (j \times m + i) \times \text{len} Loc(a[i][j])=a+(j×m+i)×len

(解释：前面完整的有 jjj 列，每列有 mmm 个元素；当前列已经走了 iii 个元素。）

2. 考点：稀疏矩阵

在计算机中，若矩阵中许多元素的值相同或为零，为了节省存储空间，通常会对矩阵进行压缩存储——只存非零元素或有效数据。常见的特殊矩阵包括对称矩阵、上/下三角矩阵和对角矩阵等。

2.1 下三角矩阵 (Lower Triangular Matrix)

  • 定义​：主对角线上方的元素（不包括对角线）全部为常数 ccc（通常为 000）的方阵。

  • 压缩策略：只需按行优先顺序存放主节点及下三角部分的元素（共 n(n+1)2\frac{n(n+1)}{2}2n(n+1)​ 个元素），常数 ccc 可以不存或只存一份。

  • 一维数组下标计算公式（假设行标 iii、列标 jjj 均从 000 开始，矩阵为 n×nn \times nn×n）：

    Index=(i+1)×i2+j\text{Index} = \frac{(i + 1) \times i}{2} + j Index=2(i+1)×i​+j

(解释：前面完整的有 iii 行，第 kkk 行有 k+1k+1k+1 个元素，总共前面的元素个数为 *1+2+⋯+i=i(i+1)21 + 2 + \dots + i = \frac{i(i+1)}{2}1+2+⋯+i=2i(i+1)​*​ ；在当前第 iii 行中，已经走过了 jjj 列，加上当前元素即可)

2.2 上三角矩阵 (Upper Triangular Matrix)

  • 定义​：主对角线下方的元素（不包括对角线）全部为常数 ccc（通常为 000）的方阵。

  • 压缩策略：只需按行优先顺序存放主对角线及上三角部分的元素。

  • 一维数组下标计算公式（假设行标 iii、列标 jjj 均从 000 开始）：

    Index=(2n−i+1)×i2+j−i\text{Index} = \frac{(2n - i + 1) \times i}{2} + j - i Index=2(2n−i+1)×i​+j−i

(解释：前面完整的有 iii 行，第 000 行有 nnn 个元素，第 111 行有 n−1n-1n−1 个元素……第 i−1i-1i−1 行有 n−i+1n-i+1n−i+1 个元素。通过等差数列求和得到前面所有行的元素总数，再加上当前行中从第 iii 列到第 jjj 列的偏移量)

2.3 对角矩阵 (Diagonal Matrix / 帯状矩阵)

  • 定义​：矩阵中的​非零元素都集中在以主对角线为中心的对称带状区域中。
  • 特点：除了主对角线及其相邻的少数几条对角线之外，其余元素全部为零。

2.4 稀疏矩阵的表示形式 (Sparse Matrix)

当矩阵中绝大多数元素为零时，为了不浪费大量空间存储零值，通常采用以下形式进行压缩存储：

  • 三元组表 (Triple Table) ：

    • 每个非零元素用一个三元组表示：​ ​(行号, 列号, 元素值)​ 。
    • 例如：​(1, 1, 5)​、​(1, 2, 10) 等。

  • 存储结构：

    • 三元组顺序表：采用顺序存储结构（如一维数组）来依次存放各个非零元素的三元组。
    • 十字链表 (Cross Linked List) ​：三元组表的​链式存储结构，适用于非零元素个数和位置经常发生变化的稀疏矩阵，方便进行行列双向的链式遍历与修改。

4.1 题目一

题目： 已知 555 行 555 列的二维数组 aaa 中的各元素占两个字节，求元素 a[2][3]a[2][3]a[2][3] 按行优先存储的存储地址。（假设数组首地址为基地址 aaa）

4.1.1 详细解析与计算过程

  1. 提取已知条件：

    • 数组规模：555 行 555 列，即总行数 m=5m = 5m=5，总列数 n=5n = 5n=5。
    • 目标元素：a[2][3]a[2][3]a[2][3]，即行下标 i=2i = 2i=2，列下标 j=3j = 3j=3（下标均从 000 开始）。
    • 元素大小：每个元素占 len=2\text{len} = 2len=2 个字节。
    • 存储方式：​按行优先存储（Row-Major Order）。

  2. 套用按行存储的地址计算公式：

    Loc(a[i][j])=a+(i×n+j)×len\text{Loc}(a[i][j]) = a + (i \times n + j) \times \text{len} Loc(a[i][j])=a+(i×n+j)×len

  • 代入数据计算：

    • 前面完整行和当前行已走过的元素总数（偏移量）为：

      i×n+j=2×5+3=10+3=13（个元素）i \times n + j = 2 \times 5 + 3 = 10 + 3 = 13 \text{（个元素）} i×n+j=2×5+3=10+3=13（个元素）

    • 结合图中的口诀（行标准：行标 ×\times× 总列数 +++ 列标）：

      前面经过了第 000 行和第 111 行（共 222 行，每行 555 个元素，计 101010 个），再加上第 222 行已经走过的第 0、1、20\text{、}1\text{、}20、1、2 列（共 333 个元素），总共间隔了 131313 个元素。

    • 计算总字节偏移量并得出最终地址：

      Loc(a[2][3])=a+13×2=a+26\text{Loc}(a[2][3]) = a + 13 \times 2 = a + 26 Loc(a[2][3])=a+13×2=a+26

4.1.2 总结与答案

  • 元素 a[2][3]a[2][3]a[2][3] 前面的元素个数： 131313 个
  • 存储地址表达式： a+26a + 26a+26 （如果以字节为单位计算偏移量）

4.2 题目二

题目： 二维数组 a[1..N,1..N]a[1..N, 1..N]a[1..N,1..N] 可以按行存储或按列存储。对于数组元素 a[i,j]a[i, j]a[i,j] (1≤i,j≤N1 \le i, j \le N1≤i,j≤N)，当（ ）时，在按行和按列两种存储方式下，其偏移量相同。

  • A. i≠ji \neq ji=j
  • B. i=ji = ji=j
  • C. i>ji > ji>j
  • D. i<ji < ji<j

详细解析：

  1. 明确下标范围：

    • 本题中二维数组的下标从 111 到 NNN 开始计算（即总行数为 NNN，总列数为 NNN）。

  2. 推导下标从 111 开始时的存储偏移量公式：

    • 按行存储（Row-Major） ：前面有 i−1i-1i−1 行（每行 NNN 个元素），当前行已经过了 j−1j-1j−1 个元素。因此元素 a[i][j]a[i][j]a[i][j] 前面的元素个数（偏移量）为：

      Offsetrow=(i−1)×N+(j−1)\text{Offset}_{\text{row}} = (i - 1) \times N + (j - 1) Offsetrow​=(i−1)×N+(j−1)

    *. ​按列存储（Column-Major） ：前面有 j−1j-1j−1 列（每列 NNN 个元素），当前列已经过了 i−1i-1i−1 个元素。因此元素 a[i][j]a[i][j]a[i][j] 前面的元素个数（偏移量）为：

    extOffsetcol=(j−1)×N+(i−1)ext{Offset}_{\text{col}} = (j - 1) \times N + (i - 1) extOffsetcol​=(j−1)×N+(i−1)

  • 令两者相等进行求解：
    要使两种存储方式下的偏移量相同，即 Offsetrow=Offsetcol\text{Offset}_{\text{row}} = \text{Offset}_{\text{col}}Offsetrow​=Offsetcol​：

    (i−1)N+(j−1)=(j−1)N+(i−1)(i - 1)N + (j - 1) = (j - 1)N + (i - 1) (i−1)N+(j−1)=(j−1)N+(i−1)

移项整理得：

(i−1)N−(j−1)N=(i−1)−(j−1)(i - 1)N - (j - 1)N = (i - 1) - (j - 1) (i−1)N−(j−1)N=(i−1)−(j−1)

(i−j)(N−1)=i−j(i - j)(N - 1) = i - j (i−j)(N−1)=i−j

(i−j)(N−1)−(i−j)=0(i - j)(N - 1) - (i - j) = 0 (i−j)(N−1)−(i−j)=0

(i−j)(N−2)=0(i - j)(N - 2) = 0 (i−j)(N−2)=0

  • 因为矩阵的维数 NNN 通常大于 222（即 N−2≠0N-2 \neq 0N−2=0），所以要使等式恒成立，必须满足：

    i−j=0  ⟹  i=ji - j = 0 \implies i = j i−j=0⟹i=j

  • 结论：
    当 i=ji = ji=j 时（即位于矩阵的主对角线上的元素），无论按行存储还是按列存储，其计算出的偏移量完全相同。因此正确选项为 ​B。

正确答案：B。

4.3 题目三

4.3.1 矩阵结构分析

以三对角矩阵为例，非零元素仅分布在主对角线 (i=ji = ji=j) 以及​上下两条紧邻的次对角线（i=j−1i = j - 1i=j−1 和 i=j+1i = j + 1i=j+1) 上。

  • 步骤一：计算前 i−1i-1i−1 行的非零元素总数

    • 第 111 行有 222 个元素。

    • 第 222 到 i−1i-1i−1 行共 (i−2)(i - 2)(i−2) 行，每行 333 个元素。

    • 前 i−1i-1i−1 行总数：

      2+3×(i−2)=2+3i−6=3i−42 + 3 \times (i - 2) = 2 + 3i - 6 = 3i - 4 2+3×(i−2)=2+3i−6=3i−4

  • 步骤二：计算当前第 iii 行中 ai,ja_{i,j}ai,j​ 前面的元素个数
    三对角矩阵中第 iii 行的合法列下标只能是 j∈{i−1,i,i+1}j \in \{i-1, i, i+1\}j∈{i−1,i,i+1}：

    将上述关系用列标 jjj 统一表达为：j−i+1j - i + 1j−i+1
