SpringIOC和DI

本篇是 Spring 的入门篇：介绍 Spring 框架的概况与体系结构，完成第一个 Spring 程序，然后重点学习 Spring 配置文件（Bean 的配置、实例化方式、依赖注入），最后通过数据源案例体会用 Spring 管理第三方对象的完整过程。

1. Spring概述

1.1 Spring是什么

Spring 是分层的 Java SE/EE 应用 full-stack 轻量级开源框架，以 IOC（Inverse Of Control，反转控制）和 AOP（Aspect Oriented Programming，面向切面编程）为内核。

动态代理和SpringAOP

本篇先学习动态代理——它是不修改源码就能对方法进行增强的技术，也是 AOP 的底层原理；再介绍 AOP 的相关概念，最后通过 XML 配置的方式完成基于 Spring 的 AOP 开发。

1. 动态代理

1.1 什么是动态代理

动态代理是一种在不修改源码的情况下对方法进行增强的技术。

  • 特点：字节码随用随创建，随用随加载；
  • 作用：在不修改源码的基础上对方法增强；
  • 学习目的：为学习 AOP 的原理做准备。

Spring注解开发_整合Junit

本篇介绍 Spring 的两种简化配置方式：先用原始注解代替 XML 中的 Bean 配置，再用新注解完全取代 XML 配置文件；最后学习 Spring 整合 Junit，解决测试代码中重复获取容器的问题。

1. Spring注解开发

Spring 是轻代码重配置的框架，配置比较繁琐。随着项目的扩大，配置会变得非常臃肿，影响开发效率。为了解决这个问题，注解开发成为一种趋势：用注解代替 XML 配置文件可以简化配置，提高开发效率。

这同样体现了一种"约定大于配置"的思想。
