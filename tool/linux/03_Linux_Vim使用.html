Linux_Vim使用

本篇介绍 Vi/Vim 文本编辑器的基本情况、三种操作模式，以及各模式下常用的光标移动、插入、删除、查找与保存命令。

1. Vi/Vim 简介

1.1 是什么

Vi/Vim 是一款文本编辑器，类似于 Windows 下的记事本、notepad++。

1.2 用途

  • 编写代码；
  • 编写文档；
  • 记录简短信息。

1.3 为什么要学习 Vi/Vim

  • Vi/Vim 是 Linux 系统默认的编辑器；
  • 多数时候 Linux 都不安装 GUI，作为服务器操作系统，经常需要通过修改配置文件来修改配置，因此需要掌握 vi/vim。

2. Vi/Vim 的三种操作模式

2.1 三种操作模式简介

模式说明
编辑模式vi 将输入的字符作为命令对待，并对每个命令做出回应，但不显示这些字符
插入模式vi 将输入的字符作为正文内容，放进正在编辑的文件中
最后一行模式所有以冒号 : 开始的命令都会使 vi 处于最后一行模式，光标移动到屏幕最底一行，输入的命令将在该行显示

2.2 三种操作模式转换

2.3 编辑模式下移动光标

命令功能
[n]G将光标定位到第 n 行开始处
G将光标定位到文件结束处
gg将光标定位到文件开始处
H光标定位到屏幕顶部
M光标定位到屏幕中间
L光标定位到屏幕底部

2.4 编辑模式下进入插入模式

命令功能
i从光标当前位置开始插入
a从光标当前位置的下一个字符开始插入
o在光标位置的下行插入一个空行，再进行插入
O在光标位置的上一行插入一个空行，再进行插入
I从光标所在行的开头开始插入正文
A从光标所在行的末尾开始插入正文

2.5 编辑模式下删除和修改文本

命令功能
u撤销前面多次修改
[n]x删除光标后 n 个字符
[n]X删除光标前 n 个字符
[n]dd删除从当前行开始的 n 行
[n]yy复制从当前行开始的 n 行
p把剪切板上的内容插入到当前行
dw删除单词
.执行上一次操作
shift+zz保存并退出当前文件

2.6 编辑模式下的查找

命令功能
/字符串从光标开始处向文件尾查找字符串
?字符串从光标开始处向文件首查找字符串
n同一方向重复上一次查找命令
N反方向重复上一次查找命令

提示

去除查找高亮：在最后一行模式输入 nohl。

2.7 最后一行模式常用命令

命令功能
w保存当前文件
q退出 vi
wq保存当前文件并退出
x保存当前文件并退出，同 wq
q!不保存文件并退出
set number设置行号显示
