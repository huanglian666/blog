网络接入技术

1. 考点：有线接入技术

  • 常见技术标准：

    • 公用交换电话网络 (PSTN)
    • 数字数据网 (DDN)
    • 综合业务数字网 (ISDN)
    • 非对称数字用户线路 (ADSL)
    • 同轴光纤技术 (HFC)

  • ADSL 的三种常见接入方式：

    1. 静态 IP，专线方式。
    2. PPPoA（异步传输点对点）。
    3. PPPoE（以太网上点对点）。

URL

1. 考点：HTTP 连接与数据传输七步流程

  1. 输入 URL：在浏览器中输入 URL，并按下回车键。
  2. DNS 解析：浏览器向 DNS 服务器发出域名解析请求并获得对应的 IP 地址。
  3. 建立 TCP 连接：根据目的 IP 地址和端口号，与服务器建立 TCP 连接。
  4. 发送请求：浏览器向服务器发送数据请求。
  5. 传输数据：服务器将网页数据发送给浏览器。
  6. 断开连接：通信完成，断开 TCP 连接。
  7. 渲染显示：浏览器解析收到的数据并显示网页内容。

网络的诊断命令

1. 考点：核心网络诊断命令

  • ping 命令：用于检查网络是否连通。排查错误时遵循由近及远的原则，首先使用 ping 127.0.0.1 来检查本机 TCP/IP 协议栈，若能 PING 通则说明本机协议栈无问题。
  • tracert （Linux 下为 traceroute ）命令：用于确定 IP 数据包访问目标所采取的路径，若网络不通，能够定位到具体哪个结点不通。
  • nslookup 命令：用于查询 DNS 记录。
  • netstat 命令：用于显示网络连接、路由表和网络接口信息。
