JavaSE 是整个 Java 学习路线的地基，覆盖从环境搭建、基础语法、面向对象，到 IO、多线程、反射等进阶主题。无论后续走向 Web 开发、后端框架还是微服务，这一板块的内容都是前置要求。零基础可以直接从这里开始，有其他语言经验的话可以快速过一遍基础部分，重点放在面向对象与集合。

## 学习路线

建议按 **JavaSE基础 → JavaSE高级** 的顺序学习：基础部分沿"语法 → 面向对象 → 常用类 → 集合 → 异常"的脉络推进，是后面所有内容的词汇表；高级部分的 IO、多线程、网络编程和反射则是理解 JavaWeb、Spring 框架原理的钥匙。学完本板块即可进入 [Web开发](/web/) 板块，继续 Servlet 或前端基础。
