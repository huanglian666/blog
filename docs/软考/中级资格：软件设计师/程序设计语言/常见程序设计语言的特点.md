# 常见程序设计语言的特点

## 1. 考点：常见程序设计语言的特点

1. **Fortran语言**（科学计算，执行效率高）
2. **Pascal语言**（为教学而开发的，表达能力强）
3. **C语言**（指针操作能力强，高效）
4. **Lisp语言**（函数式程序语言，符号处理，人工智能）
5. **C++语言**（面向对象，高效）
6. **Java语言**（面向对象，中间代码，跨平台）
7. **C#语言**（面向对象，中间代码，.Net）
8. **Prolog语言**（逻辑推理，简洁性，表达能力，数据库和专家系统）
9. **Python语言**（解释型，面向对象，脚本语言）
10. **PHP语言**（解释型，脚本语言，嵌入HTML文档的动态语言）

## 2. 经典例题

### 2.1 题目一

> **题目：** 以下关于脚本语言的叙述中，正确的是（ **C** ）。
>
> A、脚本语言是通用的程序设计语言  
> B、脚本语言更适合应用在系统级程序开发中  
> C、脚本语言主要采用解释方式实现  
> D、脚本语言中不能定义函数和调用函数

**解析：**

1. **执行方式：**  脚本语言（如 Python、JavaScript 等）通常不需要提前编译成独立的二进制机器码，而是**主要采用解释方式实现**（边解释边执行），因此 C 是正确的。
2. **特点与应用：**  脚本语言主要用于编写控制软件应用程序、自动化任务或网页动态效果的脚本，**不适合应用在系统级程序开发**（系统级开发通常使用 C、C++ 等），排除 B；脚本语言完全可以定义和调用函数，排除 D；它们多用于特定应用场景，并非传统意义上的通用系统级程序设计语言，排除 A。

**正确答案：C。** 

### 2.2 题目二

> **题目：** Python 语言的特点不包括（ **B** ）。
>
> A、跨平台、开源  
> B、编译型  
> C、支持面向对象程序设计  
> D、动态编程

**解析：**

1. **执行方式：**  Python 是一种典型的**解释型语言**（脚本语言），而不是编译型语言（编译型语言如 C、C++）。因此 B 选项“编译型”是错误的，符合题意“不包括”。
2. **其他特点：**  Python 具备良好的跨平台性与开源特性（A 正确），支持面向对象程序设计（C 正确，前面知识点中也提到 Python 是“解释型，面向对象，脚本语言”），并且支持动态编程与动态类型（D 正确）。

**正确答案： B。**
