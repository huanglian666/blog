# 系统测试的基本原则

## 1. **考点：测试的基本概念及分类**

1. 尽早、不断地进行测试
2. 程序员避免测试自己设计的程序
3. 既要选择有效、合理的数据，也要选择无效、不合理的数据
4. 修改后应进行回归测试
5. 尚未发现的错误数量与该程序已发现错误数成正比

## 2. 经典例题

### 2.1 题目一

> **题目：**  以下关于软件测试的叙述中，不正确的是（ ）。
>
> - A、在设计测试用例时应考虑输入数据和预期输出结果
> - B、软件测试的目的是证明软件的正确性
> - C、在设计测试用例时，应该包括合理的输入条件
> - D、在设计测试用例时，应该包括不合理的输入条件

 **【解析】**

- **正确答案：B**
- **解析说明：**

  - **关于选项 B（软件测试的目的是证明软件的正确性）** ​：说法不正确。软件测试的目的是​**发现软件中的错误**，而不是证明软件的正确性。测试只能证明软件存在错误，不能证明软件没有错误。
  - **其他选项说明**：

    - **A、在设计测试用例时应考虑输入数据和预期输出结果**：正确。测试用例应包括输入数据和预期的输出结果。
    - **C、在设计测试用例时，应该包括合理的输入条件**：正确。测试用例应包含合理的输入条件。
    - **D、在设计测试用例时，应该包括不合理的输入条件**：正确。测试用例也应包含不合理的输入条件，以检验系统的容错能力。

**正确答案：B（软件测试的目的是证明软件的正确性）。** 

### 2.2 题目二

> **题目：**  招聘系统要求求职的人年龄在20岁到60岁之间（含），学历为本科、硕士或者博士，专业为计算机科学与技术、通信工程或者电子工程。其中（ ）不是好的测试用例。
>
> - A、20，本科，电子工程
> - B、18，本科，通信工程
> - C、18，大专，电子工程
> - D、25，硕士，生物学

 **【解析】**

- **正确答案：C**
- **解析说明：**

  - **关于选项 C（18，大专，电子工程）** ​：这个测试用例有​**两个部分不合规**​——年龄 18 岁不符合（应≥20 岁），学历大专不符合（应为本/硕/博）。一个测试用例中同时包含多个无效条件，一旦测试失败，​**不容易定位到底是年龄规则出错还是学历规则出错**，不利于缺陷定位，因此它不是好的测试用例。
  - **其他选项说明**：

    - **A、20，本科，电子工程**：年龄、学历、专业全部符合要求，属于有效输入，能验证正常流程，是合理的测试用例。
    - **B、18，本科，通信工程**​：只有年龄 18 岁​**不符合**，学历和专业均符合，只包含一个无效条件，便于定位缺陷，是好的测试用例。
    - **D、25，硕士，生物学**​：只有专业生物学​**不符合**，年龄和学历均符合，同样只包含一个无效条件，便于定位缺陷，是好的测试用例。

**正确答案：C（18，大专，电子工程）。**
