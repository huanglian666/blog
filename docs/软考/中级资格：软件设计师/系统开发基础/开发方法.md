# 开发方法

## 1. **考点：常见开发方法**

### 1.1 **结构化方法（瀑布模型）**

- **核心思想**：用户至上，自顶向下，逐步分解（求精）。
- **核心特点**：

  - 严格区分工作阶段：每阶段有明确的任务和结果。
  - 强调系统开发过程的整体性和全局性。
  - 系统开发过程工程化，文档资料标准化。
- **适用场景**：需求明确、稳定的项目。
- **记忆总结**​：结构化 \= 瀑布模型，重文档、重阶段、自顶向下。

### 1.2 **原型法**

- **核心特点**：更好的复用性。
- **适用场景**：用户需求不清、需求经常变化，且系统规模不是很大也不太复杂的情况。
- **记忆总结**​：原型法 \= 快速构建、反复修改、需求不清时使用。

### 1.3 **面向对象方法**

- **核心思想**：关键在于建立一个全面、合理、统一的模型。
- **阶段划分**：分析、设计、实现三个阶段，界限不明确。
- **记忆总结**​：面向对象 \= 对象驱动、迭代无间隙、分析/设计/实现界限模糊。

### 1.4 **对比总结**

|开发方法|核心特点|关键词|
| ----------| ------------------------------------------------------| --------------------|
|**结构化方法（瀑布模型）**|用户至上、严格分阶段、文档标准化、自顶向下逐步分解|阶段清晰、文档驱动|
|**原型法**|更好的复用性|需求不清、快速原型|
|**面向对象方法**|建立全面、合理、统一的模型；分析/设计/实现界限不明确|对象驱动、界限模糊|

## 2. 经典例题

### 2.1 题目一

> **题目：**  若用户需求不清晰且经常发生变化，但系统规模不太大且不太复杂，则最适宜采用（ ）开发方法，对于数据处理领域的问题，若系统规模不太大且不太复杂，需求变化也不大，则最适宜采用（ ）开发方法。
>
> - A、结构化
> - B、Jackson
> - C、原型化
> - D、面向对象

 **【解析】**

- **正确答案：第一空选 C，第二空选 A。**
- **解析说明：**

  - **第一空：用户需求不清晰且经常发生变化，但系统规模不太大且不太复杂**。

    - 这属于典型的 **原型化方法** 适用场景。
    - 原型法比较适合于 **用户需求不清、需求经常变化** 的情况，当系统规模不是很大也不太复杂时，采用该方法比较好。
    - 题干中“需求不清晰且经常发生变化”“规模不太大且不太复杂”两个特征均指向原型化方法。
  - **第二空：数据处理领域的问题，系统规模不太大且不太复杂，需求变化也不大**。

    - 这属于典型的 **结构化方法** 适用场景。
    - 结构化方法（瀑布模型）以文档为驱动，适合于 **需求很明确** 的软件项目。
    - 题干中“数据处理领域”“需求变化也不大”说明需求相对稳定，适合结构化方法。
  - **其他选项说明**：

    - **B、Jackson**：属于面向数据结构的开发方法，主要用于数据处理类问题，但题干更强调“需求变化不大 + 规模不大”，标准答案仍取结构化方法。
    - **D、面向对象**：更适合大型、复杂、需求可能变化的系统，与题干“规模不太大且不太复杂”不完全吻合。

**正确答案：第一空 C（原型化），第二空 A（结构化）。**
