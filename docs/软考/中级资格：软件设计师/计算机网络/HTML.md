# HTML

## 1. 考点：HTML 基本结构与核心要点

- **网页框架**：

  - `<html>` 表示网页代码的起始和终止。
  - `<title>` 用于定义文档的标题，它是 `<head>` 部分中唯一必需的元素。

| ------| --------------------------------|

## 3. 经典例题

### 3.1 题目一

> **题目：**  页面的标记对中（ ）用于表示网页代码的起始和终止。
>
> - A、`<html></html>`
> - B、`<head></head>`
> - C、`<body></body>`
> - D、`<meta></meta>`

 **【解析】**

- **正确答案：A**
- **解析说明：**

  - **关于选项 A（**  **`<html></html>`**  **）** ：`<html>` 是 HTML 文档的根标记，用于表示网页代码的起始和终止，所有其他 HTML 元素都包含在 `<html>` 和 `</html>` 之间。
  - **其他选项说明**：

    - **B、**  **`<head></head>`** ：用于定义文档的头部信息，如标题、元数据等。
    - **C、**  **`<body></body>`** ：用于定义文档的主体内容，即页面上显示的内容。
    - **D、**  **`<meta></meta>`** ：用于定义文档的元数据，如字符集、关键字等。

**正确答案：A（**  **`<html></html>`**  **）。**
