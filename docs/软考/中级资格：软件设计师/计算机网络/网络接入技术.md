# 网络接入技术

## 1. 考点：有线接入技术

- **常见技术标准**：

  - 公用交换电话网络 (PSTN)
  - 数字数据网 (DDN)
  - 综合业务数字网 (ISDN)
  - 非对称数字用户线路 (ADSL)
  - 同轴光纤技术 (HFC)
- **ADSL 的三种常见接入方式**：

  1. **静态 IP**，专线方式。
  2. **PPPoA**（异步传输点对点）。
  3. **PPPoE**（以太网上点对点）。

## 2. 考点：无线接入技术

- **常见技术标准**：

  - IEEE 802.11 (WiFi)
  - IEEE 802.15 (蓝牙 Bluetooth)
  - 红外 (IrDA)
  - WAPI
- **关键技术指标对比**：

  - **802.11n 无线局域网**​：传输距离在 100\~300米。
  - **Zigbee**​：传输距离 50\~300米，最大特点是可自组网，网络节点数最大可达 65,000 个。
  - **蓝牙 (Bluetooth)** ​：传输距离 2\~30米，速率为 1Mbps。

## 3. 经典例题

### 3.1 题目一

> **题目：**  使用 ADSL 接入 Internet，用户端需要安装（ ）协议。
>
> - A、PPP
> - B、SLIP
> - C、PPTP
> - D、PPPoE

 **【解析】**

- **正确答案：D**
- **解析说明：**

  - **关于选项 D（PPPoE）** ：PPPoE（Point-to-Point Protocol over Ethernet，以太网上的点对点协议）是 ADSL 接入 Internet 时常用的协议，用于在以太网上建立点对点连接并进行用户认证。
  - **其他选项说明**：

    - **A、PPP**：点对点协议，用于拨号连接，但不直接用于 ADSL 以太网接入。
    - **B、SLIP**：串行线路网际协议，是较早的拨号协议，已较少使用。
    - **C、PPTP**：点对点隧道协议，主要用于 VPN。

**正确答案：D（PPPoE）。**

### 3.2 题目二

> **题目：**  下列无线网络技术中，覆盖范围最小的是（ ）。
>
> - A、802.15.1 蓝牙
> - B、802.11n 无线局域网
> - C、802.15.4 ZigBee
> - D、802.16m 无线城域网

 **【解析】**

- **正确答案：A**
- **解析说明：**

  - **关于选项 A（802.15.1 蓝牙）** ​：蓝牙是一种短距离无线通信技术，覆盖范围通常在 **10 米**以内，是所列技术中覆盖范围最小的。
  - **其他选项说明**：

    - **B、802.11n 无线局域网**​：覆盖范围一般在 **100 米**左右。
    - **C、802.15.4 ZigBee**​：覆盖范围通常在 **10~100 米**之间。
    - **D、802.16m 无线城域网**​：覆盖范围可达​**数公里**，是所列技术中覆盖范围最大的。

**正确答案：A（802.15.1 蓝牙）。**
