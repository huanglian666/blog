# 网络的诊断命令

## 1. 考点：核心网络诊断命令

- **​`ping`​**​ **命令**​：用于检查网络是否连通。排查错误时遵循由近及远的原则，首先使用 ​`ping 127.0.0.1` 来检查本机 TCP/IP 协议栈，若能 PING 通则说明本机协议栈无问题。
- **​`tracert`​**​ **（Linux 下为** ​**​`traceroute`​**​ **）命令**：用于确定 IP 数据包访问目标所采取的路径，若网络不通，能够定位到具体哪个结点不通。
- **​`nslookup`​**​ **命令**：用于查询 DNS 记录。
- **​`netstat`​**​ **命令**：用于显示网络连接、路由表和网络接口信息。

## 2. 考点： ​`ipconfig`​ / ​`ifconfig` 配置与诊断命令

- **基本功能与显示级别**：

  - **核心功能**：用于显示 TCP/IP 网络配置值，例如 IP 地址、MAC 地址、网关地址等。
  - **​`ipconfig`​**：仅显示简要信息，无法查看 DHCP 服务的开启情况。
  - **​`ipconfig /all`​**：显示本机 TCP/IP 配置的详细信息，能为 DNS 和 WINS 服务器显示其已配置且所要使用的附加信息（如 IP 地址），并且显示内置于本地网卡中的物理地址。
- **在 DHCP 服务中的应用**：

  - **​`ipconfig /all`​**：可用于查看详细信息，从而判断 DHCP 服务是否已启用。
  - **​`ipconfig /renew`​**：更新所有适配器，由 DHCP 客户端手动向服务器刷新请求。
  - **​`ipconfig /release`​**：释放 IP 地址租约，该命令只能在向 DHCP 服务器租用其 IP 地址的计算机上起作用。
- **在 DNS 服务中的应用**：

  - **​`ipconfig /flushdns`​**：用于清除本地 DNS 缓存。
  - **​`ipconfig /displaydns`​**：用于显示本地 DNS 的内容。
  - **​`ipconfig /registerdns`​**：供 DNS 客户端手动向服务器进行注册。

## 3. 经典例题

### 3.1 题目一

> **题目：**  测试网络连通性通常采用的命令是（ ）。
>
> - A、netstat
> - B、ping
> - C、msconfig
> - D、cmd

 **【解析】**

- **正确答案：B**
- **解析说明：**

  - **关于选项 B（ping）** ：ping 命令用于测试网络连通性，通过发送 ICMP 回显请求报文并接收回显应答，判断目标主机是否可达。
  - **其他选项说明**：

    - **A、netstat**：用于查看网络连接、路由表、接口统计等信息。
    - **C、msconfig**：用于系统配置，与网络连通性测试无关。
    - **D、cmd**：是 Windows 的命令行解释器，不是测试连通性的命令。

**正确答案：B（ping）。** 

---

### 3.2 题目二

> **题目：**  使用（ ）命令可以释放当前主机自动获取的 IP 地址。
>
> - A、ipconfig/all
> - B、ipconfig/reload
> - C、ipconfig/release
> - D、ipconfig/reset

 **【解析】**

- **正确答案：C**
- **解析说明：**

  - **关于选项 C（ipconfig/release）** ：该命令用于释放当前主机通过 DHCP 自动获取的 IP 地址。
  - **其他选项说明**：

    - **A、ipconfig/all**：显示所有网络适配器的完整 TCP/IP 配置信息。
    - **B、ipconfig/reload**：不是标准命令。
    - **D、ipconfig/reset**：不是标准命令。

**正确答案：C（ipconfig/release）。** 

---

### 3.3 题目三

> **题目：**  下列命令中，不能用于诊断 DNS 故障的是（ ）。
>
> - A、netstat
> - B、nslookup
> - C、ping
> - D、tracert

 **【解析】**

- **正确答案：A**
- **解析说明：**

  - **关于选项 A（netstat）** ：netstat 用于查看网络连接、路由表、接口统计等信息，不能用于诊断 DNS 故障。
  - **其他选项说明**：

    - **B、nslookup**：用于查询 DNS 域名解析，是诊断 DNS 故障的常用命令。
    - **C、ping**：可以通过 ping 域名来测试 DNS 解析是否正常，从而诊断 DNS 故障。
    - **D、tracert**：可以追踪到目标主机的路由路径，也能间接反映 DNS 解析情况，用于诊断 DNS 故障。

**正确答案：A（netstat）。**
