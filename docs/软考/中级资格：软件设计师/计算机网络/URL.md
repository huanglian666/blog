# URL

## 1. 考点：HTTP 连接与数据传输七步流程

1. **输入 URL**：在浏览器中输入 URL，并按下回车键。
2. **DNS 解析**：浏览器向 DNS 服务器发出域名解析请求并获得对应的 IP 地址。
3. **建立 TCP 连接**：根据目的 IP 地址和端口号，与服务器建立 TCP 连接。
4. **发送请求**：浏览器向服务器发送数据请求。
5. **传输数据**：服务器将网页数据发送给浏览器。
6. **断开连接**：通信完成，断开 TCP 连接。
7. **渲染显示**：浏览器解析收到的数据并显示网页内容。

> **核心提示**：在传统 HTTP/1.0 默认非持久连接情况下，一旦 Web 服务器向浏览器发送了请求数据，它就会关闭 TCP 连接。

## 2. 考点：URL

### 2.1 URL 基础概念

- **Internet 地址**：包含域名格式和 IP 地址格式。
- **URL（Uniform Resource Locator）** ：统一资源定位符，是互联网上标准资源的地址。互联网上的每个文件都有一个唯一的 URL，它包含的信息指出了文件的位置以及浏览器应该怎么处理它。

### 2.2 URL 结构与语法格式

- **常规结构示例**​：​`协议名://主机名.组名.最高层域名`​ （例：​`[https://www.educity.cn/](https://www.educity.cn/)`）。
- **详细标准格式**​：​`protocol://hostname[:port]/path/filename`

### 2.3 URL 各组成部分详解

- **​`protocol`​**​ **（传输协议）** ：

  - 指定使用的传输协议，最常见的是 HTTP 或者 HTTPS 协议，也可以有其他协议，如 file、ftp、gopher、mms、ed2k 等。
  - **缺省规则**：缺省时为 HTTP，其他协议不能缺省。
- **​`hostname`​**​ **（主机名）** ：

  - 是指主机名，即存放资源的服务域名或者 IP 地址。
  - 主机名可能为第一个字段，也可能指域名。
- **​`port`​**​ **（端口号）** ：

  - 是指各种传输协议所使用的默认端口号。
  - **缺省规则**：缺省时为 80（对应 HTTP），其他非默认端口不能缺省。
- **​`path`​**​ **（路径）** ：

  - 是指路径，由一个或者多个 ​`/` 分隔，一般用来表示主机上的一个目录或者文件地址。
- **​`filename`​**​ **（文件名）** ：

  - 是指文件名，该选项用于指定需要打开的具体文件名称。

### 2.4 域名访问的常见误区

- **非正式域名不能直接打开**：

  - 一般情况下，一个 URL 可以采用“主机名.域名”的形式打开指定页面，也可以单独使用“域名”来打开指定页面。
  - 但这种实现前提是需要进行相应的 DNS 设置和对应，因此​**非正式域名不能直接打开**​（例如通常 ​`abc.com`​ 无法直接打开 ​`[www.abc.com](https://www.abc.com)`）。

## 3. 经典例题

### 3.1 题目一

> **题目：**  在浏览器的地址栏中输入 [xxxyftp.abc.can.cn](https://xxxyftp.abc.can.cn/)，在该 URL 中（ ）是要访问的主机名。
>
> - A、xxxyftp
> - B、abc
> - C、can
> - D、cn

 **【解析】**

- **正确答案：A**
- **解析说明：**

  - 在域名 ​`xxxyftp.abc.can.cn` 中，从左到右依次为：

    - **主机名**​：​`xxxyftp`
    - **三级域名**​：​`abc`
    - **二级域名**​：​`can`
    - **顶级域名**​：​`cn`
  - 因此，**主机名**是 ​`xxxyftp`。

**正确答案：A（xxxyftp）。** 

---

### 3.2 题目二

> **题目：**  在地址栏输入 [www.abc.com](https://www.abc.com/)，浏览器默认的应用层协议是（ ）。
>
> - A、HTTP
> - B、DNS
> - C、TCP
> - D、FTP

 **【解析】**

- **正确答案：A**
- **解析说明：**

  - **关于选项 A（HTTP）** ​：在浏览器地址栏输入网址时，默认使用的应用层协议是 ​**HTTP**（超文本传输协议）。
  - **其他选项说明**：

    - **B、DNS**：用于域名解析，不是浏览器访问网页时使用的应用层协议。
    - **C、TCP**：属于传输层协议，不是应用层协议。
    - **D、FTP**：用于文件传输，不是浏览器默认访问网页的协议。

**正确答案：A（HTTP）。** 

---

> **题目：**  因特网中的域名系统（Domain Name System）是一个分层的域名，在根域下面是顶级域，以下顶级域中，（ ）属于国家顶级域。
>
> - A、NET
> - B、EDU
> - C、COM
> - D、UK

 **【解析】**

- **正确答案：D**
- **解析说明：**

  - **关于选项 D（UK）** ​：​`UK`​ 是英国的国家顶级域名，属于​**国家顶级域**。
  - **其他选项说明**：

    - **A、NET**：属于通用顶级域，用于网络服务机构。
    - **B、EDU**：属于通用顶级域，用于教育机构。
    - **C、COM**：属于通用顶级域，用于商业机构。

**正确答案：D（UK）。**
