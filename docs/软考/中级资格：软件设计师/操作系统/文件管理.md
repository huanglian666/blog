# 文件管理

## 1. 考点：文件相关概念

- **文件**：具有符号名的、在逻辑上具有完整意义的一组相关信息项的集合。
- **逻辑结构**：

  - 有结构的记录式文件（如手写补充的 ​`.idx` 索引文件等）
  - 无结构的流式文件（如手写补充的 ​`.txt` 文本文件等）
- **物理结构**：

  - 连续结构
  - 链接结构
  - 索引结构
  - 多个物理块的索引表

### 1.1 **常见文件类型及其结构分类**

为了帮你更好地理解文件的逻辑结构，以下列举一些常见的文件类型，看看它们分别属于​**流式文件**​（无结构）还是​**记录式文件**（有结构）：

#### 1.1.1 **流式文件（无结构文件）**

- **特点**：文件内的信息是以字节（Byte）为单位流式管理的，文件内部没有明显的逻辑结构划分，操作系统不关心文件的具体内容含义，只把它看作是一串连续的字节流。
- **常见类型**：

  - **文本文件** (​`.txt`​, ​`.md`​, ​`.html`​, ​`.c`​, ​`.java` 等)：纯文本或代码文件。
  - **可执行文件与库** (​`.exe`​, ​`.dll`​, ​`.so`​, ​`.com`)。
  - **压缩与归档文件** (​`.zip`​, ​`.tar`​, ​`.gz`​, ​`.rar`)。
  - **多媒体文件** (​`.mp3`​, ​`.mp4`​, ​`.jpg`​, ​`.png`)：虽然内部有复杂的编码格式，但对操作系统而言，它们也是按字节流存储的。

#### 1.1.2 **记录式文件（有结构文件）**

- **特点**：文件由一个或多个“记录”组成，每个记录包含若干个数据项。记录通常具有相同的结构（定长记录）或不同的结构（变长记录），常用于数据库系统或信息管理。
- **常见类型**：

  - **数据库文件** (​`.db`​, ​`.sqlite`​, ​`.mdf`)：内部按行（记录）、列（字段）组织数据。
  - **表格/结构化数据文件** (​`.csv`​, ​`.xls`​, ​`.xlsx`)：虽然平时用文本或表格软件打开，但在系统逻辑上它们是由明确的行记录和字段构成的。
  - **索引/日志文件** (​`.idx`​, ​`.log`)：通常包含固定格式的日志条目或索引记录便于快速检索。

## 2. 考点：文件目录

- **文件目录**：

  - **文件目录项 / 文件的说明 / 文件控制块 (FCB)** ：

    - **基本信息类**：文件名、文件的物理地址、文件长度和文件块数等。
    - **存储控制信息类**：文件的存储权限（读、写、执行权限等）。
    - **文件属性**：只执行、隐含、只读、读/写、共享、系统。
    - **使用信息类**：文件建立日期、最后一次修改/访问日期、当前使用的信息、打开文件的进程数以及在文件上的等待队列等。
  - **目录结构**：

    - **一级目录结构**：线性结构，查找速度慢，不允许重名，且无法实现文件共享等。
    - **二级目录结构**：主文件目录 (MFD) + 用户目录 (UFD)。
    - **三级目录结构**：树型目录结构（多级目录结构）。

## 3. 经典例题

### 3.1 题目一

> **题目**：若系统在将（ **A** ）文件修改的结果写回磁盘时发生崩溃，则对传感/系统的影响相对较大。
>
> - **选项**：A、目录
> - B、空闲块
> - C、用户程序
> - D、用户数据

**解析**：

- 目录文件（包含文件控制块FCB、物理地址等元数据）是文件系统管理文件和组织结构的基石。
- 若目录文件修改结果写回时崩溃，会导致整个文件系统的元数据结构处于不一致状态，进而引起大面积文件丢失、路径混乱或系统瘫痪，其破坏远大于仅影响单个文件的用户数据或用户程序崩溃。
