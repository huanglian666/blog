### 1.4 解题技巧：仔细对比伪代码和代码，找到得分点。

#### 1.4.1 题目

 **【模式匹配基本概念】**

- **定义**：模式匹配是指给定主串 $t$ 和子串 $s$，在主串 $t$ 中寻找子串 $s$ 的过程，其中 $s$ 称为模式。
- **返回值**：如果匹配成功，返回 $s$ 在 $t$ 中的位置；否则返回-1。

 **【KMP算法优化说明】**

- **优化机制**​：KMP算法用 ​`next` 数组对匹配过程进行了优化。
- **伪代码执行步骤**：

  1. 在串 $t$ 和串 $s$ 中，分别设比较的起始下标 $i=j=0$。
  2. 如果串 $t$ 和串 $s$ 都还有字符，则循环执行下列操作：

     - **条件 (1)** ：如果 $j=-1$ 或者 $t[i]=s[j]$，则将 $i$ 和 $j$ 分别加1，继续比较 $t$ 和 $s$ 的下一个字符。
     - **条件 (2)** ：否则，将 $j$ 向右滑动到 ​`next[j]` 的位置，即 $j=next[j]$。

```C
......
int kmp( int *next, char *t,char *s, int lt, int ls )

    else  return -1;
}

```

**答案：（1）：j < ls（2）：t[i] == s[j]（3）：j = next[j]。**
