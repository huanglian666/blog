# 标准化

## 1. 考点：标准分类与代表组织

### 1.1 标准分类与代表组织对比表

|**标准级别**|**概念与定义**|**代表组织 / 标准代号**|
| --| ------------------------------------------------------| ------------------------------------------------------------------------------------------------------------|
|**国际标准**|由国际标准化组织制定的标准|**ISO**​（国际标准化组织）、​**IEC**（国际电工委员会）等|
|**国家标准**|由国家标准化专责机构制定并发布的标准|**GB**​（中国）、​**ANSI**​（美国）、​**BS**​（英国）、​**JIS**（日本）|
|**区域标准**|又称为地区标准，由某个特定地理区域内的标准化组织制定|**PASC**​（太平洋地区标准会议）、​**CEN**​（欧洲标准委员会）、​**ASAC**​（亚洲标准咨询委员会）、​**ARSO**（非洲地区标准化组织）|
|**行业标准**|由行业协会或部门制定的标准|**GJB**​（中国军用标准）、​**MIL-S**​（美国军用标准）、​**IEEE**（美国电气电子工程师协会）|
|**地方标准**|由国家的地方一级行政机构制定的标准|各省、自治区、直辖市制定的地方标准（如 DB 前缀）|
|**企业标准**|企业自行制定，在企业内部生效的标准|Q/ 前缀标准（仅在企业内部适用）|
|**项目规范**|特定项目内部约束的规范文档|针对具体工程/研发项目的专项规范|

### 1.2 核心解题技巧与高频考点

1. **代号匹配题（选择题高频）** ：

   - **GB** $\rightarrow$ 中国国家标准
   - **ANSI** $\rightarrow$ 美国国家标准
   - **BS** $\rightarrow$ 英国国家标准
   - **JIS** $\rightarrow$ 日本国家标准
   - **IEEE** $\rightarrow$ 美国电气电子工程师协会（属于行业标准）
   - **GJB** $\rightarrow$ 中国军用标准（属于行业标准）
2. **标准层级效力高低**：

   - 效力从高到低：​**国际标准 &gt; 国家标准 &gt; 行业标准 &gt; 地方标准 &gt; 企业标准**。
   - **原则**：下级标准不得低于或违背上级强制性标准的要求。

## 2. 考点：标准代号与结构规范

### 2.1 国际与国外标准代号组成

- **构成格式**：标准代号 + 专业类号 + 顺序号 + 年代号
- **记忆示例**​：​`ISO/IEC 17025-2017`（包含组织代号、专业分类、顺序编号以及发布年份）

### 2.2 我国国家标准代号（高频必考）

- **强制性国家标准**​：​`GB`（“国标”汉语拼音首字母，具有法律强制执行力）
- **推荐性国家标准**​：​`GB/T`（“推”字拼音首字母 T）
- **指导性技术文件**​：​`GB/Z`（“指”字拼音首字母 Z）
- **实物标准代号**​：​`GSB`（“国实标”拼音组合）

### 2.3 行业、地方与企业标准代号

- **行业标准代号**：由汉语拼音大写字母组成

  - **经典示例**​：电子行业为 ​`SJ`​（“电”字原由四机部管理，沿用四机拼音）、通信行业为 ​`YD`​（邮电）、软件/信息化行业常见 ​`JR`​（金融）、​`GJB`（军标）等。
- **地方标准代号**​：由 ​`DB` 加上省级行政区代码的前两位组成

  - **结构**​：​`DB` + 行政区划代码前两数字（如 DB11 为北京、DB31 为上海、DB53 为云南）。
- **企业标准代号**​：由 ​`Q/` 加上企业代码组成

  - **结构**​：​`Q/` + 企业标识码（“企”字拼音首字母 Q）。

### 2.4 核心解题口诀

- **强制 GB，推荐 GB/T，指导 GB/Z，实物 GSB**。
- **地方看 DB，企业看 Q/，行业看拼音字母**。
