# Linux_安装

本篇介绍 Linux 系统的安装流程：先在 Windows 上安装 VMware Workstation 虚拟机，再创建虚拟机并安装 CentOS 7，最后配置远程连接与文件传输工具。

## 1. 安装 VMware Workstation 虚拟机软件

VMware Workstation 是一款虚拟机软件，可以在 Windows 系统中模拟出一台独立的计算机。按照安装向导操作即可：

### 2.2 安装 CentOS

![启动虚拟机进入安装界面](./_pic/image-20210621155335997.png)

操作步骤：

- 在虚拟机运行界面点击鼠标左键，鼠标和键盘就会被虚拟机捕获；
- 在当前界面下按上或下方向键选择 **Install CentOS 7**，然后回车。

> [!TIP]
> 如果想把键盘和鼠标的控制权交还给 Windows，按 `ctrl+alt` 即可。

## 3. 远程连接

一般情况下，Linux 作为服务器操作系统，不可能安装在本地，多数时候都是安装在远程主机上。我们通常使用**远程连接**的方式操作 Linux 系统，连接需要用到**网络三要素**中的 IP 地址和端口号。

### 3.1 获取当前 CentOS 系统的 IP 地址

打开终端，执行以下命令：

```sh
$ ifconfig
```
