# IDEA简介

## 1. 什么是 IDEA

IDEA 全称 IntelliJ IDEA，是 Java 编程语言开发的集成环境（IDE）。IntelliJ 在业界被公认为最好的 Java 开发工具之一，尤其在智能代码助手、代码自动提示、重构、JavaEE 支持、各类版本工具（Git、SVN 等）、JUnit、CVS 整合、代码分析以及创新的 GUI 设计等方面表现出色。

IDEA 是 JetBrains 公司的产品，该公司总部位于捷克共和国的首都布拉格。它的旗舰版本还支持 HTML、CSS、PHP、MySQL、Python 等语言，免费社区版只支持 Java、Kotlin 等少数语言。

中文官网：<https://www.jetbrains.com/zh-cn/idea/>

## 2. 系统要求

- Microsoft Windows 10/8/7
- 4 GB RAM 最低，推荐 8 GB
- 2 GB 硬盘空间 + 至少 1 GB 缓存空间
- 最低分辨率 1024×768
- JDK 1.6 或更高版本
