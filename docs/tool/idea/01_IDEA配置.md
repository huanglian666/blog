# IDEA配置

本篇整理 IntelliJ IDEA 的常用全局设置，包括主题、字体、编码、自动导入、代码编译等；不同版本的 IDEA 入口略有差异，文中以 2020 版截图为准。

启动界面点击 **Customize --> All Settings**，即可进入全局设置界面（2019 版为 **Configure --> Settings**）：

进入后的全局设置界面如下图所示：

![IDEA 全局设置界面](./pic/02.jpg)

IDEA 的全局设置以后都在该界面中进行。

## 14. 重置 IDEA 试用开始时间

IDEA 旗舰版安装后有 30 天的试用期，试用期过后需要激活。可以通过不断**重置 IDEA 试用开始时间**实现无限期试用，从而达到间接激活的目的。要完成该项操作需要**安装相关插件**。

> [!WARNING]
> 此方式仅供个人学习参考，商用请购买正版授权。

### 14.1 重置插件安装

![从磁盘安装插件界面](./pic/19.jpg)

点击 **Install Plugin from Disk** 之后，会让我们选择本地的插件文件（`ide-eval-resetter-2.1.14.jar`），选择并安装之后会提示重启 IDEA，到此插件安装完成。

### 14.2 重置插件设置

插件安装完成之后，按照下面的操作，勾选 **Auto reset before per restart**，之后每次重启 IDEA 都会重新设置开始试用时间：

![勾选自动重置选项](./pic/20.jpg)

![重置插件设置完成效果](./pic/21.jpg)
