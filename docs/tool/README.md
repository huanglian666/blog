日常开发离不开的工具与环境部署笔记：IDEA 的配置与快捷键、Maven 依赖管理、Git 版本控制、Linux 基本操作，以及 Nginx 服务器部署。各工具相互独立，不需要按顺序通读，遇到问题时当作手册查阅即可；Linux 部分建议在进入框架学习前过一遍，因为后续的环境搭建和项目部署都会用到。

## 学习路线

推荐优先级：**IDEA → Maven → Git → Linux → Nginx**。IDEA 和 Maven 是写 Java 代码每天都要打交道的基础设施，建议先熟悉；Git 是团队协作的必修课；Linux 一节覆盖常用命令、Vim、软件安装与防火墙设置，是部署的前提；Nginx 放到最后，与 [SpringCloud](/springCloud/) 板块的部署实践配合食用更佳。
