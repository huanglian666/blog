Web 开发板块分两条线：**前端基础**覆盖 HTML、CSS、JavaScript 及 jQuery、Ajax 等经典技术栈，**JavaWeb** 则是 Java 服务端开发的基础——从 HTTP 与 Tomcat 讲起，到 Servlet、JSP、Filter 的完整体系。建议先具备 [JavaSE](/javase/) 基础再学 JavaWeb 部分；前端部分没有硬性前置，但 JavaWeb 中的 JSP 页面会用到 HTML 基础。

## 学习路线

可以按 **前端基础 → JavaWeb** 的顺序学习，先对页面的结构与交互有概念，再看服务端如何接收请求、生成响应；纯后端方向的读者也可以直接学 JavaWeb，遇到页面细节再回查前端部分。JavaWeb 中的 Servlet 请求响应模型是理解 [SpringMVC](/framework/) 的直接前置，学完本板块即可无缝进入框架学习。
