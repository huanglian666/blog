# 设计模式-导学

本篇是设计模式系列课程的导学篇，介绍课程背景、课程概述、课程特色、整体内容安排、适用人群以及学习方法建议，帮助你在正式学习之前对整个课程有一个全局的认识。

## 1. 课程背景

随着软件开发人员人数的增多，一些公司急需高端人才。作为一名高端人才，设计面向对象软件是必不可少的能力，而软件设计需要很深的功力，设计模式就是必须掌握的内容。本课程就是带领你进入设计模式的世界。

## 2. 课程概述

本课程从设计模式的相关概念开始，再到软件设计原则，重点讲解 23 种设计模式，针对每一种模式都配备了相关的代码。最后通过一个综合案例将常用的设计模式使用起来。

## 3. 课程特色

市面上已经有很多的设计模式教程，这套课程的特色如下：

- **从基础开始**：只要有 JavaSE 的基础都可以学习；
- **全面**：覆盖设计模式本身、模式的变形以及开发中的实际使用方式；
- **案例经典**：学习 Spring 框架是最好的提升途径，Spring 框架将面向对象体现得淋漓尽致。

## 4. 课程内容

整个课程分为 3 大部分：

| 部分 | 内容 |
| --- | --- |
| 第一部分：设计模式相关介绍 | 设计模式的概述、UML 图、软件设计原则 |
| 第二部分：设计模式的学习 | 创建型模式、结构型模式、行为型模式 |
| 第三部分：综合案例 | 自定义 Spring 的 IOC 功能 |

## 5. 适用人群

本课程定位是设计模式的入门课程，同时也会聊到设计模式在 Spring 中的使用。对于要从事高级工程师及架构师工作的人来说，设计模式、数据结构和算法是必须灵活运用的，这类读者可以从本课程开始学习。学习本课程需要具备的基础如下：

- 有面向对象的基础；
- 使用过 Spring 框架（后面有一个综合案例，会模拟 Spring 实现 IOC 功能）。

## 6. 学习方法及建议

- **多思考**：多问为什么，多对比几个相似模式之间的区别；
- **多实践**：课程中的代码需要多敲几遍，通过代码加深对设计模式的理解；
- **多翻源码**：学习源码可以对设计模式的应用有更好的理解。

## 7. 小结

本篇只是一个"路线图"：整个系列先打好概念与设计原则的地基（第一部分），再按创建型、结构型、行为型三类逐个攻破 23 种模式（第二部分），最后通过手写 IOC 的综合案例把知识串起来（第三部分）。带着这个整体框架进入后面的章节，学习目的性会更强。
