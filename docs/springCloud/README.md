微服务与 SpringCloud 生态学习笔记：从单体架构的演变讲起，覆盖 Docker 容器化、Redis 缓存、RocketMQ 消息队列、ElasticSearch 搜索引擎、SpringCloudAlibaba 微服务组件，最后落到一个综合实战项目。本板块前置要求最多——建议学完 [框架学习](/framework/)（尤其是 SpringBoot）和 [工具|部署](/tool/)（Linux）之后再开始。

## 学习路线

建议按 **Docker → Redis → MQ → ElasticSearch → SpringCloudAlibaba → 综合项目** 的顺序推进：先用 Docker 解决服务的容器化部署，再依次掌握缓存、消息、搜索三类中间件的使用场景，然后进入 Nacos、Gateway、Sentinel、Seata 等微服务组件，最后在综合项目里把全部内容串起来。各中间件章节相对独立，可以按需跳读，但综合项目建议放最后。

## 栏目速览

- **Docker**：容器化与部署基础
- **Redis**：缓存中间件
- **MQ**：消息队列（RocketMQ）
- **ElasticSearch**：搜索引擎
- **SpringCloudAlibaba**：Nacos / Gateway / Sentinel / Seata / Sleuth 微服务组件
- **综合项目**：微服务实战项目笔记
